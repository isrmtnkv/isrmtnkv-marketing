Персональный сайт isrmtnkv — Сыромятников Игорь

Дизайн адаптирован из локального проекта hfp: светлая палитра, кобальтовый акцент #2448D8, крупная типографика, плавающая навигация, круглые кнопки со стрелками.

Первый экран пересобран: один заголовок «Превращаю трафик в клиентов», имя под заголовком, бренд isrmtnkv в меню. Убраны повторяющиеся подводки и три мини-блока. Вместо блока каналов — «Обо мне» с фотографией, возрастом 24 года и опытом 7+ лет. Добавлены отдельные списки навыков, каналов трафика и инструментов. Сохранены русская и английская версии, все 7 кейсов, скриншоты, ссылки, фильтры и API отправки.

Запуск: Node.js 18 или новее, npm start. Зависимостей для установки нет. Откройте http://localhost:3000. Можно также открыть index.html напрямую.

На localhost и при открытии файла форма проверяет ввод и показывает сообщение о предпросмотре, не отправляя заявку. На опубликованном сайте используется исходный LEAD_ENDPOINT. Боевая отправка в ходе редизайна не выполнялась. Серверная часть и аналитические интеграции сохранены.

Проверено в браузере: 320, 390, 768 и 1440 px; русский и английский; фильтрация кейсов, переключение слайдов, мобильное меню, якорные ссылки и локальная форма. Переполнения по горизонтали и ошибок JavaScript не обнаружено. Кнопка бонуса ведёт на https://t.me/isrmtnkvbot.

Файлы редизайна: index.html, assets/redesign.css, assets/igor.jpg, assets/favicon.svg.
