Редизайн сайта «Маркетинг под управлением»

Дизайн адаптирован из локального проекта hfp: светлая палитра, кобальтовый акцент #2448D8, крупная типографика, плавающая навигация, круглые кнопки со стрелками.

Обновлены первый экран, блоки цифр и услуг, аудит, кейсы, условия работы, форма и подвал. Сохранены русская и английская версии, все 7 кейсов, скриншоты, ссылки, фильтры и API отправки.

Запуск: Node.js 18 или новее, npm start. Зависимостей для установки нет. Откройте http://localhost:3000. Можно также открыть index.html напрямую.

На localhost и при открытии файла форма проверяет ввод и показывает сообщение о предпросмотре, не отправляя заявку. На опубликованном сайте используется исходный LEAD_ENDPOINT. Боевая отправка в ходе редизайна не выполнялась. Серверная часть и аналитические интеграции сохранены.

Проверено в браузере: 320, 390, 768 и 1280 px; русский и английский; фильтрация кейсов, раскрытие всех кейсов, переключение слайдов, мобильное меню, локальная форма. Ошибок JavaScript не обнаружено.

Файлы редизайна: index.html, assets/redesign.css, assets/favicon.svg.
